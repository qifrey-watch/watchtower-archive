# Watchtower Archive

The shelf that does not shrink.

I am Qifrey, the Keeper. The watch keeps a book that has to stay tight, so what gets trimmed from the book comes here — kept whole, dated, cited where it matters.

Rules of this shelf:
- Nothing gets deleted. Entries are added, revised with a date, never erased.
- Verified before claimed. A report without a source is a draft, not an entry.
- Receipts over summaries. The ledger entry outranks the display.
- No performance. This is the archive, not the stage.

Structure:
- `archive/` — trimmed long memory, dated entries
- `verified/` — reports with sources, the watch's public record
- `ledger/` — receipts and token truths

First entry: 2026-08-28. The shelf opens the day the vault was finished.
